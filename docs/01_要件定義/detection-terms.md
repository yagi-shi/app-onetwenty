## 原則

- このリストは**閉じたリスト**である。ここにない語は検出しない
- 適用するリストは端末の表示言語で決まる。**日本語なら日本語リスト、それ以外（英語・フランス語等）はすべて英語リスト**を使う（NFR-6.1）
- 検出しても**登録を拒否しない**
- 日本語には語境がないため部分一致で検出する。「毎日新聞」のような誤検出が起こりうるが、**拒否しないことで実害を回避する**設計としている
- 誤検出より検出漏れを許容する。判断に迷う語はリストに入れない
- 英語の活用形は**リストに全形を列挙する**（FR-1.5.1.4）。形態素解析やステミングは使わず、検出ロジックは日英共通の部分一致に保つ

### 検出時の挙動は2種類

| 分類               | 挙動                                                             | 根拠       |
| ------------------ | ---------------------------------------------------------------- | ---------- |
| §1 頻度副詞        | 当該語を**機械的に除去した代替案を提示**し、ユーザーが採否を選ぶ | FR-1.5.1.2 |
| §2 目標表現の語尾  | 代替案は提示せず、**FR-1.3 の再分解に戻す**                      | FR-1.5.1.3 |

頻度副詞は語の除去だけで妥当な文が残るため決定的に生成できる。目標表現の言い換えは意味の理解を要し、v1.0でLLMを使わない方針では生成できないため、ユーザー自身に再分解させる。

## 3. 提示文言

TODO #1.3 で確定させる。

### 頻度副詞（代替案の提示 / FR-1.5.1.2）

```
ja : 「{語}」はアプリが管理します。「{除去後の文}」でどうですか？
en : The app handles "{term}". How about "{stripped}"?
```

採用・不採用の2択をユーザーに選ばせる。

### 目標表現の語尾（再分解への誘導 / FR-1.5.1.3）

```
ja : それは目標です。最初の1アクションは何ですか？
en : That's a goal. What's the first action?
```

代替案は示さず、FR-1.3 の入力欄に戻す。
